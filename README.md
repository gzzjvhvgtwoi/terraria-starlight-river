## Overview

Starlight River is an ambitious Terraria content mod adding a star-and-cosmos themed questline, new biomes carved into the fabric of the sky and void, over a dozen fully custom bosses with multi-phase fight scripts, hundreds of unique weapons and accessories featuring non-standard mechanics like charges and triggered abilities, and a modular ability system replacing vanilla class specialization.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Starlight River** delivers the features you need in a clean, intuitive package.
